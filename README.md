*** NHL Dynamic Wallpaper By Cooper ***

[Download the Latest Version](https://github.com/AndrewCooper69/NHLDynamicWallpaperByCooper/releases/latest)

*** This application is used to create wallpaper images for an NHL team's calendar, as well as NHL standings and statistics. ***

*** The calendar goes on one monitor, and the standings and statistics screen goes on another monitor. ***

*** You can choose which monitor to put them on, or omit one or the other.  They work on vertical or horizontal monitors. ***

*** The application will update the calendar and statistics at 6am EST each day (or when PC is next turned on), or manually using a provided shortcut. ***


*** It is essentially a dynamic wallpaper, but does not use system resources as it is not a program that is always on. ***

*** It uses Windows Task Scheduler to run the program once a day, so the program creates a new wallpaper each day that is a static image file. ***
